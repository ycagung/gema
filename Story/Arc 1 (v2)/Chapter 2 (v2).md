"Gema, kerjakan soal nomor sembilan belas!" Aku tersentak dari lamunanku. Bu Karin tiba-tiba melontarkan jebakan agar aku memperhatikan pelajaran matematikanya kembali. Terima kasih sudah menarikku dari per-Anya-an ini, bu. Kutengok soal nomor sembilan belas di buku, ternyata soal integral biasa.

$$\int \sin x \cos x \, dx$$

Aku berdiri, mengambil spidol di meja Bu Karin lalu mulai menulis di papan tulis.

"Ada tiga metode," ujarku sambil menulis. "Metode pertama adalah mensubstitusi $u = \sin x$, lalu $du = \cos x \, dx$. Setelah perhitungan sederhana jawabannya adalah..."

$$\int \sin x \cos x \, dx = \int u \, du = \frac{1}{2}u^2 + C = \frac{1}{2}\sin^2 x + C$$

"Metode kedua mirip dengan yang pertama. Kita substitusi $u = \cos x$, lalu $du = -\sin x \, dx$. Jawaban akhirnya jadi..."

$$\int \sin x \cos x \, dx = -\int u \, du = -\frac{1}{2}u^2 + C = -\frac{1}{2}\cos^2 x + C$$

"Yang ketiga menurut saya lebih menarik karena kita pakai identitas sudut ganda. Kita tahu kalau $2 \sin x \cos x = \sin 2x$, maka $\sin x \cos x$ adalah $\frac{1}{2}\sin 2x$. Kalau kita aplikasikan ke soal tadi, maka..."

$$\int \sin x \cos x \, dx = \frac{1}{2}\int \sin 2x \, dx = -\frac{1}{4}\cos 2x + C$$

Kutarik garis vertikal untuk membatasi papan tulis lalu aku pindah ke sisi sebelahnya.

"Mengapa ketiga jawaban itu benar?" Ujarku sambil terus menulis. "Karena perbedaannya hanya pada konstanta. Kalau ada yang lupa, identitas Pythagoras utama mengatakan bahwa $\sin^2 x + \cos^2 x = 1$."

$$\frac{1}{2}\sin^2 x - \left(-\frac{1}{2}\cos^2 x\right) = \frac{1}{2}\left(\sin^2 x + \cos^2 x\right) = \frac{1}{2}$$ $$\frac{1}{2}\sin^2 x - \left(-\frac{1}{4}\cos 2x\right) = \frac{1}{2}\sin^2 x + \frac{1}{4}\left(1 - 2\sin^2 x\right) = \frac{1}{4}$$

"Perbedaan konstanta akan hilang ketika diturunkan. Jadi semua jawaban di atas akan punya bentuk turunan yang sama."

$$\frac{d}{dx}\left(\frac{1}{2}\sin^2 x\right) = \frac{d}{dx}\left(-\frac{1}{2}\cos^2 x\right) = \frac{d}{dx}\left(-\frac{1}{4}\cos 2x\right) = \sin x \cos x$$

Kuletakkan spidolku. "Bagian $+C$ menyerap perbedaan konstantanya." 

Tulisanku ternyata sudah memenuhi papan tulis lebar itu. Lalu aku berputar menghadap kelas yang sedang menganga. Ah, ada tiga yang sedang menguap.
